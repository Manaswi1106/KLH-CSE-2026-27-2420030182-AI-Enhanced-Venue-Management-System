# AI-Powered Detection of Phishing Websites Using URL and Webpage Features

## Project Description

This project aims to develop an AI-powered system for detecting phishing websites using machine learning techniques. The system analyzes URL and webpage-related features to classify a website as either phishing or legitimate.

The project uses the D1 Phishing Webpage Dataset. The dataset contains phishing and legitimate webpages and includes URL character sequence features, webpage text features, hyperlink features, and login form features.

The project includes data preprocessing, feature extraction, model training, performance evaluation, and development of a web application for phishing website detection.

- Phishing webpages: 27,280
- Benign webpages: 32,972

Features include:

- Webpage text features
- Hyperlink features
- Login form features
